# 荣耀 MagicOS AirPods 支持原理与逆向记录

> 本文记录本模块背后的实机调查过程，供后续维护/适配参考。

## 1. 功能归属

MagicOS 11 的原生 AirPods 支持由 **「智慧空间」`com.hihonor.magichome`**（10.60.08.300）实现，
核心类：

```
com.hihonor.magichome.devicemanager.data.AppleAirDevManager
```

相关辅助类：`AirpodsConstants`、`AppleAirDevManager$2`（BLE/AACP 回调）、
`AppleAirDevManager$AirPodsDataBatteryCallBack`（电量回调）等。

系统里另有两个相关组件，但职责不同：

| 组件 | 职责 |
|---|---|
| `com.hihonor.magichome` | AirPods 识别、电量/噪声控制、控制中心卡片（本模块目标） |
| `com.huawei.smartaudio` | 耳机侧功能配置/OTA |
| `com.hihonor.audioaccessorymanager` | 通用音频配件管理（共享耳机等） |

## 2. 型号白名单

`AppleAirDevManager` 用如下逻辑判断是否支持某副耳机（logcat 原文）：

```
MagicHome: [AppleAirDevManager]isSupportAirPodsDevice deviceArr is not null!
MagicHome: [AppleAirDevManager]isSupportAirPodsDevice prodIdList is not null!
MagicHome: [AppleAirDevManager]isSupportAirPodsDevice prodIdList contains = false
MagicHome: [AppleAirDevManager]supportAirPodsDevice: supportAirPodsDevice = false
```

- `prodIdList` 是**云端下发**的、受支持 Apple 产品型号列表；
- 本地缓存位于 `/data/data/com.hihonor.magichome/databases/batteryServices.db`
  的 `batteryConfig` 表（JSON），其中已支持型号包含：
  AirPods 1/2/3/4（降噪/非降噪）、AirPods Pro 1/2/2 USB-C、**AirPods PRO 3**、AirPods Max 2020/2024，
  每项带荣耀内部型号码（如 Pro 2 = `00M0VQ`、PRO 3 = `00FDAQ`）；
- **AirPods 5（机身型号 A3441）不在列表内**，因此判定失败、整个链路跳过。

## 3. 解决方案

AirPods 5 的荣耀内部型号码无法凭空得知（由荣耀云端分配），因此**注入白名单不可行**；
改 APK 又会被系统签名校验拦住。最终采用 **LSPosed hook**：

- 作用域：`com.hihonor.magichome`
- 目标类：`AppleAirDevManager`
- 动作：把该类的 boolean 判定方法（0 参数 / 单 String 参数）强制返回 `true`，
  绕过 `prodIdList` 白名单检查。

模块使用 **libxposed 现代 API 102**（`io.github.libxposed:api`），因为
LSPosed 2.2.1 下自制的 legacy（API 82）精简模块不会被加载。

## 4. 实测环境

| 项目 | 版本 |
|---|---|
| 设备 | LDY-AN00（荣耀 Magic8 Pro Air） |
| 系统 | MagicOS 11.0.0.110 (SP7C00E110R103P1) / Android 17 (SDK 36) |
| 智慧空间 | 10.60.08.300 |
| LSPosed | 2.2.1 (API 102) + Zygisk Next |
| 耳机 | AirPods 5（A3441，序列号 KXRR6FXY7P） |

## 6. 未覆盖 / 后续

- 若荣耀在未来版本把 AirPods 5 加入云端白名单，本模块可以卸载；
- 不同版本 `AppleAirDevManager` 的类名/包名可能变化，届时改 `TARGET_CLS` 即可；
- 若荣耀把该逻辑迁移到 `com.hihonor.audioaccessorymanager`，需扩展作用域与目标类。
